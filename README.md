# Plugins

Claude Code plugins, published as one plugin marketplace.

| Plugin | What it does |
|---|---|
| [`sqlserver-dba`](sqlserver-dba/) | Read-only SQL Server performance and reliability skills for DBAs: health checks, workload hotspots, query tuning with proven minimal fixes, deadlock analysis, verification of vendor releases and hot-fixes, a daily dashboard, and write-ups with a reproduction kit for the vendor. |

## Install

In Claude Code:

```
/plugin marketplace add <owner>/Plugins
/plugin install sqlserver-dba@dba-plugins
```

Replace `<owner>/Plugins` with this repository's owner and name as shown on GitHub (or its URL), then start a new session. Each plugin's own README covers its setup and requirements.
